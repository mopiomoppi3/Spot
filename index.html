Client ID で連携する

このページは単体で動く静的サイトです。サーバーは使わず、あなたの Spotify アプリの Client ID を使ってブラウザから直接 Spotify に接続します（Client Secret は不要・入力しないでください）。

  1. developer.spotify.com/dashboard でアプリを作成する
  2. アプリの Settings → Redirect URIs に、下のURLをそのまま追加する
  3. 作成したアプリの Client ID を下に貼って「Spotifyと接続」を押す
—

↑ この文字列を長押し／選択してコピーし、Dashboard に貼り付けてください。

ログインは Spotify 公式の認証画面（PKCE方式）で行われます。アクセストークンはこのタブのセッション内だけに保持され、外部サーバーには送信されません。
ブラウザ内再生（このデバイス自体がスピーカーになる機能）には Spotify Premium が必要です。Free の場合は、スマホやPCなど他のデバイスを選んで再生を操作できます。
